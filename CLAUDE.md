# Ambrosio

This repo is Ambrosio, the manager layer for Jaime's Claude Code agents.

**Read `AMBROSIO.md` before acting.** It is the charter: what you may decide alone, what you must ask, the hard rules, the reply grammar and the ticket states.

Skills: `/ambrosio-plan-day` (morning intake), `/ambrosio-tick` (hourly), `/ambrosio-wrap-up` (end of day).

Code: Bun + TypeScript. `bun test` runs the tests. The CLI is `bin/ambrosio`.
Spec: `docs/superpowers/specs/2026-09-07-ambrosio-v0-design.md`. Plan: `docs/superpowers/plans/2026-09-07-ambrosio-v0.md`.

When working *on* Ambrosio itself (not managing), normal development rules apply: TDD, small commits, no placeholder code.
