# Ambrosio v0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A manager layer that dispatches Claude Code background workers per ticket, parks their questions instead of letting them block, and delivers one iMessage digest per hour until 15:00.

**Architecture:** Bun/TypeScript library plus a CLI in `~/Workspace/ambrosio`, three Claude Code skills that the manager sessions run, and three shell hooks that every worker session loads through `--settings`. Beads (`bd`) per repo holds ticket state; `claude agents --json` and `~/.claude/jobs/<id>/state.json` hold worker state; `~/.ambrosio/` holds the question queue, per-ticket memory and the journal. The official iMessage channel plugin carries messages both ways.

**Tech Stack:** Bun 1.x + TypeScript, `bd` 1.2.2 (Dolt 2.3.2), Claude Code 2.1.263 CLI, `imessage@claude-plugins-official`, `osascript`, `gh`.

**Spec:** `docs/superpowers/specs/2026-09-07-ambrosio-v0-design.md`

## Global Constraints

- Runtime: Bun (`bun test` for tests). No build step; the CLI runs TypeScript directly.
- Beads commands always take `-C <repoPath>` and `--json`; never rely on the current directory.
- `bd show <id> --json` returns an **array**; take `[0]`.
- `bd list -s a,b` takes one comma-separated value; repeating `-s` silently overwrites.
- Custom ticket statuses, set once per repo: `planning:wip,plan_review:wip,needs_input:wip,verifying:wip,in_review:wip`.
- Ticket ids look like `amb-wjg` (prefix plus hash), not sequential.
- Workers are dispatched as `claude --bg --name <ticket-id> --permission-mode auto --settings <abs path>/worker/settings.json "<prompt>"` from the repo root. Never `--dangerously-skip-permissions`.
- Hooks fail closed: on any internal error a guard prints a deny decision and exits 0.
- Working hours: 09:00 planning, digests at the top of each hour, 15:00 wrap-up, silence after. Hours come from config, never hardcoded in skills.
- Every outbound message and every applied reply is appended to `~/.ambrosio/journal/YYYY-MM-DD.md`.
- Nothing is committed in Jaime's repos without asking; Beads is initialized there with `--stealth` so its files stay out of git.
